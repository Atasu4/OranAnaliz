NEXUS APEX - Backend - Gerçek Canlı Bağlantı

Bu backend senin istediğin "kapanış oranına bakıp söyle" sistemini gerçek API'lere bağlıyor.

5 Dakikada Canlıya Alma

  1. API Anahtarlarını Al (Ücretsiz)

    • https://the-odds-api.com/ -> Sign up -> API Key (500 istek/ay ücretsiz, Süper Lig dahil)
    • Telegram: @BotFather'a /newbot yaz -> token al
    • @userinfobot'a yaz -> chat_id al

  2. Railway.app'e Deploy (Ücretsiz)

    • railway.app -> New Project -> Deploy from GitHub (bu klasörü GitHub'a at)
    • Variables -> ODDS_API_KEY, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID ekle
    • Deploy -> Loglarda "SCAN" göreceksin

  3. Frontend'i Bağla

    • Nexus Apex frontend'de /api/banko endpoint'ini Railway URL'ine çevir
    • Artık saat başı telefonuna: "🚨 ŞİMDİ AL: Fener KG VAR @1.72 Edge %7.4" gelecek

Ne Yapar?

  • Saat başı The Odds API'den canlı oranları çeker (Pinnacle dahil)
  • Senin xG modelinle gerçek olasılık hesaplar (Poisson Dixon-Coles)
  • Marjı temizler (no-vig)
  • En iyi marketi bulur (1 maç 1 seçim)
  • Eleştirel denetim skoru <70 ise RED
  • ONAY ise Telegram'a atar + kapanış tahmini yapar

Korelasyon Koruması

Aynı maça 2 bahis atmaz. KG VAR + ÜST aynı anda geliyorsa sadece yüksek edge'liyi atar.

Maliyet

  • The Odds API: 500 istek ücretsiz, sonra $20/ay
  • Railway: $5/ay ücretsiz kredi yetiyor
  • Telegram: Ücretsiz
